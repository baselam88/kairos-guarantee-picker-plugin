# Guarantee Typology Picker

Picks the guarantee type matched to the specific objection blocking purchase — unconditional, conditional, anti-guarantee, or implied.

A free plugin from KAIROS AI Systems — one focused tool that does one job well for a
small business: no suite to learn, no setup project, no account required beyond your
agent host.

## What it does

Name the objection first; if no objection is named, no guarantee is offered. Output: guarantee wording + the conditions that keep it honest. Never converts a guarantee into an outcome promise.

## How to use it

Add this plugin to a compatible agent host (Cursor, Grok Bot, or another
agent-plugins host), then ask in plain language, for example:

> Use the Guarantee Typology Picker to help me: picks the guarantee type matched to the specific objection blocking purchase — unconditional, conditional, anti-guarantee, or implied — I'll paste the details.

The plugin works from the facts you give it — your services, your prices, your
records. It never invents a number, a policy, or a result; anything it projects is
labelled an estimate with its basis. Drafts that would go to a customer stay drafts
until you approve them.
